# Reference

`webflow-published/` is the HTML Webflow served on 2026-08-29, captured before
the move. It is what `templates/*.html` was cut from and what the rendered
output was diffed against, byte for byte.

Kept because the custom domain has since stopped serving from Webflow. The
site itself was still reachable at anoniem.webflow.io at the time of writing,
but that is not something to rely on.
